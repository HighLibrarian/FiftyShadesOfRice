# FiftyShadesOfRice

> Please be gentle, Mr. Rice. I’m new to all this.

This is my personal Linux rice repo: a slightly overcaffeinated collection of config files, scripts, and tiny fixes I picked up from a suspicious number of tutorials. It is opinionated, a little fragile in places, and very much a work in progress.

The goal here is not perfection. It is a setup that looks good, works well enough, and makes me feel like I know what I’m doing half the time.

## What lives here

- `hypr/` for Hyprland and related window manager bits
- `waybar/` and `waybar.bak/` for panel configs, experiments, and the inevitable “that looked better yesterday” moments
- `kitty/`, `fish/`, and `starship.toml` for terminal life
- `rofi/`, `swaync/`, `waypaper/`, and other desktop polish
- assorted app and toolkit config for a coherent look across the system


## Notes

This repo is personal first and reusable second. Paths, assumptions, and choices may reflect my machine more than yours. If you borrow anything from it, expect to adapt it, rename it, and probably break it once before it behaves.
